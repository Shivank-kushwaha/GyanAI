# 🚀 GyanAI

GyanAI is a modern **AI-powered learning platform** built using the **MERN Stack**.  
The platform is designed to provide an intelligent and interactive learning experience with clean UI, responsive design, and scalable architecture.

🔗 **Live Demo:** https://gyan-ai-frontend.vercel.app/

🔗 **GitHub Repository:** https://github.com/Shivank-kushwaha/GyanAI

# ⚙️ Complete Project Setup

## 📥 1. Clone the Repository

```bash
git clone https://github.com/Shivank-kushwaha/GyanAI.git
```

---

## 📂 2. Move into Project Folder

```bash
cd GyanAI
```

---

# 🖥️ Frontend Setup

## 📦 Install Frontend Dependencies

```bash
cd client
npm install
```

## ▶️ Run Frontend

```bash
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

# 🛠️ Backend Setup

## 📦 Install Backend Dependencies

```bash
cd server
npm install
```

## ▶️ Run Backend

```bash
npm run dev
```

Backend will run on:

```bash
http://localhost:5000
```

---

# 🔑 Environment Variables Setup

Create a `.env` file inside the `server` folder.

## 📄 server/.env

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

OPENAI_API_KEY=your_openai_api_key
```
